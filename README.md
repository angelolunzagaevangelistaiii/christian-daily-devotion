# Daily Devotion & Scripture Reminder App (PHP + MySQL + JS)
A web app for Christians to read daily devotions, mark them as read, track progress, and manage content via an Admin panel.

## Setup Instructions
1. Clone the repository:

## Database Setup
2. Import the database:
- Open phpMyAdmin or MySQL client.
- Create a database named `christian_daily_devotion`.
- Import `database/database.sql`.
3. Input your MySQL database credentials to `config/config.php`.
4. Run the app in browser via localhost (XAMPP/MAMP/Laragon).
